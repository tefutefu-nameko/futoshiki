不等式の範囲図示

不等式を1〜2つ入力すると、教科書どおりの記号（●／○）で数直線上に範囲を表示します。2つ入力時は共通範囲を自動でまとめます。オフラインでも使えます。

例：

以上・以下 … 黒丸＋縦線
より大（>）… 白丸＋右上の斜線
より小（<）… 白丸＋左上の斜線

入力のしかた

  • 1つだけ入力したときは、これまでどおりその不等式を表示します。
  • 2つ入力したとき、共通範囲がある場合（例: -1<x と x<=3）→ 答えは -1 < x <= 3 にまとめ、数直線には2つの不等式も両方表示。
  • 2つとも満たす範囲がない（例: x<-2 と x>=1）→ またはとして2本の範囲線を表示。
  • 1つの欄に -1 < x <= 3 のように x が挟まれた形も入力できます。
